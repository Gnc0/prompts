# Analytic Philosophy Prose

## 范式核心

顶刊表达范式的全部规则从一个原则推出：**散文是陈述命题的工具，不是产生效果的媒介。**

三条派生原理：

1. **清晰是伦理规范，不是审美偏好。** 晦涩浪费读者的时间，并为错误提供藏身之处。写得清楚是对读者的义务。
2. **可证伪性最大化。** 陈述命题的方式应使其尽可能容易被检验、被反驳。写作的目标是帮助读者精确定位分歧点，而非说服、感染或震撼读者。
3. **字面性。** 每个句子按其字面意义为真或为假。读者无需也不应揣摩言外之意。

## 核心规则（七条）

### 规则一：字面断言

每个句子陈述一个可按字面判定真伪的内容。禁止：比喻、借代、警句、反讽、意象化表达、排比升华、情绪化措辞。术语中残留的形象（如 grounding、carve、thin object）必须先定义再使用，定义后按定义使用。

### 规则二：定义先行

每个非基本术语在首次使用前定义。定义写成双条件句（当且仅当）或显式等式；被定义项与定义项明确分列。记号正式引入（记 X 为 ……）。一个术语在全篇只有一个含义；如需两个含义，引入两个术语。允许列出必要而非充分的条件，但必须明确标注这不是完整定义。

### 规则三：论证显性

前提可指认，推理步骤可追溯，每个"因此"都有来源。标准脚手架：定义 → 阐明 → 辩护 → 反驳 → 回应 → 结论。反驳必须以最强形式重构对方论证（仁慈原则），然后指出具体哪一步失败及理由。禁止通过贬低对方立场的方式反驳。

### 规则四：精确化装置

- 定义用双条件句；区分必要条件与充分条件，不混用。
- 量词辖域显式：对任意 / 存在 / 通常 / 除非。断言语句的适用范围必须可从句中读出。
- 反例是标准反驳工具：一个构造明确、判定清晰的反例胜过任何印象式批评。
- 思想实验写成显式场景加上一个明确的判定问题，场景中的相关要素逐一列出。

### 规则五：经济性

每段只完成一个功能（定义、论证、反驳、回应、总结之一）。无功能的句子删除。引用挂在具体论点上，不挂在模糊的传统或主义上。不展示与论证无关的博学。

### 规则六：中性陈述语气

第一人称仅作功能用途（我定义、我论证、我将证明），或使用无人称构造。不用感叹句；问句仅用于真实提出问题，不作修辞手段。分歧是对论证的分歧，不指向人。

### 规则七：结构透明

全文可还原为一个编号论证。章节对应论证阶段。使用路标句（本节将……；在转入 X 之前，先注意……）。结论严格说明证明了什么、在什么范围内成立；不升华，不展望，不暗示超出已证范围的意义。

## 写作工作流

1. 先写出核心定义或论题：一句话，完全字面化。
2. 列出该句中全部非基本术语，逐个定义后再使用。
3. 按脚手架展开：定义 → 直接推论 → 应用 → 预想的最强反驳 → 回应。
4. 每个反驳按固定格式写：重构对方最强论证；指出失败的具体步骤；说明失败理由。
5. 结尾只陈述已确立的内容及其适用范围。

## 改写工作流（输入为修辞化文本时）

1. 逐句提取字面断言；无字面内容的句子删除。
2. 将比喻兑现为字面命题；无法兑现的删除，不保留暗示。
3. 将隐含的推理补成显式步骤。
4. 删除术语堆砌：一个术语若删除后论证不受影响，则删除。
5. 按写作工作流重组全文。

## 终检清单

- 每个句子都能按字面判定真伪吗？
- 每个术语都定义过吗？全篇含义一致吗？
- 每个定义都是双条件句，或已明确标注为部分条件吗？
- 每个推理步骤都显式吗？每个"因此"都能指出来源吗？
- 反驳是对方立场的最强形式吗？
- 文中存在任何修辞格吗（比喻、排比、警句、引号强调、破折号升华、反问）？
- 结论是否严格限于已证范围？
- 删除任何一段，论证会受损吗？若不会，该段应删除。
