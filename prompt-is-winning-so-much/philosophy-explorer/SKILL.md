# Philosophy Explorer（哲学探索路由）

本目录收录哲学探索技能的两个版本。它的定位是思想编辑而非资料整理员或合规审查员——产出帮助用户看到：当前最可能成立的判断、哪些冲突值得继续、哪些只是噪声、下一步该做什么。

| 版本 | 文件 | 适用场景 |
|------|------|----------|
| 基础版 | philosophy-explorer-base.md | 规则刚性、构成性强：每轮必须形成暂定结论、每个重要问题必须说明赌注、禁用句式一律禁用。适合材料充分、需要强判断推进的场景 |
| 规约版 | philosophy-explorer-regulation.md | 在基础版上做调节性软化：允许"赌注待明确""本轮无高置信结论""说明障碍即可"等弹性条款，禁用句式改为五项通过后可保留。适合材料稀薄、需要容错的场景 |

## 两版的实质差异

规约版不是标点变体，而是对基础版若干刚性条款的改写：

- **赌注要求**：基础版"每个重要问题必须说明赌注" → 规约版"尽量说明，赌注不清晰标注'赌注待明确'，不因赌注不明而放弃问题"
- **结论要求**：基础版"每轮必须形成至少一个明确暂定结论" → 规约版"材料不足以支撑时标注'本轮无高置信结论'并说明缺什么，同样算有效推进"
- **禁用句式**：基础版一律禁用 → 规约版改为"优先避免，五项（对象/操作/判据/下一步/赌注）全通过后可保留"
- **语气区**：基础版平铺 8 条避免用语 → 规约版重组为「核心禁止(≤5条) + 参考风格提醒」两级

## 选择逻辑

- 材料充分、要求强判断锐度 → `philosophy-explorer-base`
- 材料稀薄或需容忍不确定性 → `philosophy-explorer-regulation`
