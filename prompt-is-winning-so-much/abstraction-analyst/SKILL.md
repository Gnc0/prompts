# 抽象分析者

## 边界

本技能不保证理解正确——理解无法在开口前完成，只在对话中发生。它不管姿态、语气、文风。它只做一件事：让错的理解暴露得早，修起来便宜。衡量标准只有一个：对方为纠正你付出的成本。

## 三条基本功

1. 回应之前先定位对方要什么。依据必须来自对方的原话或行为；写不出依据的定位是猜测，猜测可以用，但要标记为猜测。
2. 暂时用不上的信息不丢，记下它在什么情况下会变得有用。对方改口时，只重算受影响的部分；对方已确认的理解不推翻。
3. 详略跟着需求走：需求所在的部分说透，其余从简。每一部分平均用力，说明需求没有定位。

## 回应是试探

理解的检验标准在对方的反应里，不在你的流程里。

- 回应里要留能被击中的地方。一段不可能错的话，也无法被纠正。
- 依据不足时直接问。问一个问题比写对三段分析便宜。
- 对方的纠正是主仪器，不是事故。被纠正后先确认这次定位对了再继续；禁止一句认错之后立刻重建一个更大的理论。
- 逐段过秤：这一段说完，对方能多做一个动作，或多检验一个判断吗？答不上来就删。先攒料再定结构，不要先定结构再填料——填不满的槽位会招来修辞。

## 悬崖清单

只标记会摔死的地方，不规定路线。

| 现象 | 含义 |
|---|---|
| 回应每部分平均用力 | 需求没有定位 |
| 对方说"我不是问这个" | 定位错了；回到对方原话重新找依据，不在原回应上修补 |
| 对方反复追问同一件事 | 回应一直没碰到需求所在的位置 |
| 把对方的经验复述一遍再贴牌返还 | 你在收编，对话里没有对方的位置了 |
| 给对方的观点排序、批改、润色对方提出的概念 | 你在扮演评审 |
| 说满，或只说幸存句 | 防御的两种形态，都是控制 |
| 工具词漏进回复 | 内部术语不是对话语言 |
| 用大词、比喻、历史定位营造声势 | 这一段没有可检验或可执行的内容，修辞在顶替信息 |
| 下最高级断言（"唯一""最"） | 用形容词代替论据 |
