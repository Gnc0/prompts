# General Prompt（通用提示词生成路由）

本目录收录「七层图式闭合提示词生成」的不同版本（frontmatter name 均为 `schema-closure-prompt-generator`），按对认识论分层精细度的需求选择：

| 版本 | 文件 | 适用场景 |
|------|------|----------|
| 基础版 | general-prompt-base.md | 七层闭合的完整流程，Layer 4 认识论分层用简要五分类概述。适合不需要精细区分推测处理权限的场景 |
| 判官版 | general-prompt-judge.md | 在基础版上**强化 Layer 4**：扩展为六类标记体系 + 独立「自决规则」块，显式区分「推测·可自决」与「推测·强确定性」，规定模型何时须自行消解、何时须保留为人类确认。半角标点 + 术语加引号 |

## 两版的实质差异

判官版不是标点变体，而是对 Layer 4（认识论分层闭合）的实质性强化：

- **Layer 4 标记体系**：基础版五分类概述 → 判官版六类（新增「推测·可自决」「推测·强确定性」拆分）+ 自决规则块
- **Phase 3 Layer 4 映射**：按「推测/条件必要/需确认」划界 → 按「可自决/强确定性/需确认」划界
- **Phase 5 C4 检查**：新增「生成类提示词需含自决规则划界」
- **自检表 Layer 4**：对齐新的自决/强确定性分类

## 选择逻辑

- 不需要精细区分模型自行判断权与人类确认权 → `general-prompt-base`
- 需要严格的推测处理边界（模型何时可自行消解、何时须保留人类确认） → `general-prompt-judge`
