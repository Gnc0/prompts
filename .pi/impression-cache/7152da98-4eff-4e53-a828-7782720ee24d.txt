- Publication/source kind: arXiv preprint

- Original URL: https://arxiv.org/abs/2405.15793
- Publication/source kind: arXiv preprint
- Exact abstract/result passage: “We investigate how interface design affects the performance of language model agents.”
- Minimal faithful summary and study scope: Studies how an agent-computer interface changes the actions available for repository navigation, file editing, and test/program execution. Evaluates SWE-agent on SWE-bench and HumanEvalFix; the abstract reports pass@1 of 12.5% and 87.7%, respectively.

## 3. AutoCodeRover: Autonomous Program Improvement
- Original URL: https://arxiv.org/abs/2404.05427
- Publication/source kind: arXiv preprint
- Exact abstract/result passage: “Our code search exploits the program structure in the form of classes/methods to enhance LLM's understanding of the issue's root cause, and effectively retrieve a context via iterative search.”
- Minimal faithful summary and study scope: Evaluates an iterative, structure-aware search/action workflow for GitHub-issue resolution. On SWE-bench Lite (300 real-life GitHub issues), the abstract reports 19% efficacy and average cost of $0.43.

## 4. Executable Code Actions Elicit Better LLM Agents
- Original URL: https://arxiv.org/abs/2402.01030
- Publication/source kind: arXiv preprint
- Exact abstract/result passage: “This work proposes to use executable Python code to consolidate LLM agents' actions into a unified action space (CodeAct).”
- Minimal faithful summary and study scope: Tests executable code as the action representation rather than predefined JSON/text tool calls. Across 17 LLMs on API-Bank and a newly curated benchmark, the abstract reports up to 20% higher success rate; it also describes coding/model-training and self-debugging tasks.
