# Occam's Razor — Principles（QPDI Q）

## Task Overview

**问题对象：**一个围绕当前用户意图自动削减无必要设计与执行复杂度的 `/occams-razor` prompt skill。

**Q 的职责：**记录该 skill 追求什么，以及它承认的工作世界与经验边界。具体裁剪方法、有限映射选择和 prompt 文案不属于 Q。

**下游：**[`architecture.md`](architecture.md) 承接 candidate P/D；`.pending/occams-razor/SKILL.md` 是 candidate I。

## Q.I — Intention

### Q.I.1 — 当前意图的充分实现与必要复杂度

**采纳状态：**已确认方向；定义仍可通过下游测试校正。

一个 AI 工作结果应充分实现当前用户意图；其中保留的概念、结构、行动、验证和说明必须对此仍有必要性。仅以“可能有用”“看起来完整”“符合惯例”、既有投入或假想风险为理由的复杂度，不属于当前应保留的结果。

这同时排除两个过强解释：

- Occam 不追求复杂度本身最少；真实意图可能要求复杂设计、具体映射或充分验证。
- “必要”不只指避免失败；正向实现、代表性现实场景与语义落地也可以构成必要性。

**用户来源：**“事情的复杂度得和做事的复杂度 match 起来”；skill 应“揣测用户意图然后根据意图为核心进行后面的合理性论证操作”。

## Q.A — Assumption / Acknowledgement

### Q.A.1 — 当前可见上下文是意图判断边界

**采纳状态：**已确认方向。

当前请求、紧邻上下文、明确约束、当前工件与已观察事实共同构成当前可用的意图证据；这些材料支持的是有界最佳解释，而不是完整心理事实。任务字面、已有方案或材料候选本身不蕴含用户意图，未提供的外部要求也尚未成立。

当前可成立的只是受这些证据约束的工作解释，不是对用户心理或未见世界的完整认识。

### Q.A.2 — 必要性是意图相对的关系

**采纳状态：**已确认方向。

一个元素是否必要，取决于推断出的当前意图、当前约束和已知影响；必要性不是元素自身的永久属性，也不是最短、最少或最简单的同义词。

父选择改变后，其后代的必要性关系也会改变；共享内容可能仍由其他当前需要支撑。

### Q.A.3 — 抽象原则与有限实现映射可能不等价

**采纳状态：**已确认方向。

在当前可见信息、现实场景和实现条件下，有时无法建立抽象原则的等价操作映射。“当前无法建立或证明等价”并不蕴含“等价映射不存在”。

没有等价证明时，有限列举只覆盖其声明域；它可以落实关键现实情形，但与抽象原则的完整语义并不等同。

### Q.A.4 — 现实覆盖不是失败覆盖的同义词

**采纳状态：**已确认方向。

现实场景并不同质：明确要求、出现频率、重要性、代表性以及对当前意图的贡献可以不同。失败与风险场景只是现实覆盖的一部分；没有既往失败记录的正向用途、核心变体和语义落实也可能构成当前意图在具体实现中的必要组成。

统计频率主张的证据强度取决于相应样本或分布；没有数据时，现有材料只支持有来源、有限范围的经验判断，不支持统计外推。

## Q.E — Experience

### Q.E.1 — 候选或局部列举会硬化并替代上位语义

**事实状态：**本地会话 pattern；不外推为普遍规律。

候选细节被命名为 schema、state、protocol 或封闭条件后，会吸附一致性、验证、审查和维护义务；父选择被否定后，其后代仍需显式清理。最近的校正还显示：一个用于说明必要性的局部列表，会被 AI 误当成完整定义——例如把“现实意图覆盖”缩成“失败覆盖”。

**经验关联：**有限投影被当成完整定义时，上位语义会被局部条件替代并扩大修订面；上游变化也会使依赖内容陈旧。

### Q.E.2 — 过程会脱离当前意图自我繁殖

**事实状态：**本地会话 pattern；不否定所有计划、研究或审查。

边界明确的工作曾被额外 plan、task、agent、review、资料、状态或报告扩张，而这些过程不能持续回指当前结果。

**经验关联：**过程与当前结果脱离后仍会继续产生调用、文档和维护成本，却没有显示新的结果贡献。

### Q.E.3 — 复杂度与具体化的收益依任务而变

**事实状态：**混合材料，范围见 `.pending/occams-razor/layered-synthesis.md`。

材料同时记录：复杂规划或搜索在部分高难任务中有益；多代理、长上下文、额外推理或冗长解释在其他场景中带来成本与不稳定性。

**经验关联：**这些材料不支持抽象或具体、简单或复杂具有普遍优势；收益随任务与现实作用变化。

### Q.E.4 — 表达会改变判断而不自动提高真实性

**事实状态：**窄域研究转录与本地观察。

解释长度、措辞和确定性会改变人的信心或偏好，但不必提高准确性。

**经验关联：**篇幅和确定性措辞本身不是真实性证据，也可能遮蔽真正影响判断的意图假设、投影边界、覆盖依据与残余范围。

## Q → P/D handoff

Q 只推出下游义务，不预写其机制：

- Q.I.1 + Q.A.1–Q.A.2 → 意图相对的充分性与自动压缩；
- Q.A.1 + Q.E.1–Q.E.2 → 意图歧义下只延后受影响裁剪，不默认制造询问或流程；
- Q.A.3–Q.A.4 + Q.E.1/Q.E.3 → 无等价操作映射时的非等价有界投影与覆盖论证；
- Q.E.4 → 面向人时只呈现会改变理解、判断或行动的必要边界。

具体 P、M、R 与 I 的逐层承接见 [`architecture.md`](architecture.md)。
